## 📖 Overview

The **India Culture Website** is an educational and exploratory frontend web project created to celebrate India's heritage. Spanning history, geography, arts, and gastronomy, this project provides a clean, well-structured, multi-page user experience that guides visitors through the essence of India.

---

## ✨ Key Features

- 🏛️ **Famous Landmarks & Heritage**: Highlights UNESCO World Heritage Sites and architectural marvels including the Taj Mahal, Red Fort, Qutub Minar, Hawa Mahal, and Charminar.
- 🎭 **Rich Cultural Heritage**: Explores traditional classical dance forms (Bharatanatyam, Kathak, Odissi), music, attire (Sarees, Dhotis, Kurta-Pyjama), and major festive celebrations (Diwali, Holi, Eid, Christmas).
- 🍛 **Culinary Journey**: Showcases mouth-watering North Indian gravies, South Indian delicacies (Dosa, Idli-Sambhar), street food culture, and sweet delicacies like Gulab Jamun.
- 🗺️ **States & Union Territories Directory**: Tabular reference listing Indian states, capitals, geographic data, and regional languages.
- 📝 **Interactive Contact & Registration Form**: Includes a student registration form complete with input validation, file uploads, date-pickers, and radio/checkbox selectors.
- 🧭 **Intuitive Sticky Navigation**: Seamless header and navigation bar across all pages with quick-jump links and navigation buttons.
- 🎨 **Pure Semantic HTML5 & CSS3**: Clean, maintainable stylesheets using CSS flexbox, responsive measurements (`calc()`, `vh`, `%`), and accessible form controls.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/valaprashant97/India-Culture-Website.git
```

### 2. Open the Project Folder

```bash
cd India-Culture-Website
```

### 3. Launch the Website

Because this is a static frontend project, no build tools, runtime environment, or package installations are required.

- **Option A (Direct)**: Double-click or open [`index.html`](index.html) directly in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
- **Option B (VS Code Live Server)**:
  1. Open the project folder in [Visual Studio Code](https://code.visualstudio.com/).
  2. Install the **Live Server** extension.
  3. Right-click on `index.html` and select **"Open with Live Server"**.
